# 🛒 Tienda Texas

¡Bienvenido a **Tienda Texas**! Este es un proyecto de comercio electrónico desarrollado con tecnologías web estándar y procesamiento en el servidor mediante PHP.

## 🚀 Características
* **Catálogo dinámico:** Carga de productos gestionada desde el servidor con PHP.
* **Interfaz interactiva:** Funcionalidades de carrito y filtros en el cliente con JavaScript.
* **Diseño moderno:** Estilos completamente adaptables (Responsive Design) con CSS.

## 🛠️ Tecnologías Utilizadas
* **Backend:** PHP
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)

## 📦 Cómo ejecutar el proyecto localmente

Para ver y probar este proyecto en tu computadora, necesitas un entorno de servidor local que soporte PHP (como **XAMPP**, **Laragon**, **MAMP** o **WampServer**).

1. **Clona el repositorio** dentro de la carpeta raíz de tu servidor local (por ejemplo, `C:/xampp/htdocs/` si usas XAMPP):
   ```bash
   git clone https://github.com
   ```
2. **Inicia los servicios** de Apache (y MySQL si tu proyecto utiliza base de datos) desde el panel de control de tu servidor local.
3. **Abre tu navegador** e ingresa a la siguiente dirección:
   ```text
   http://localhost/tiendatexas
   ```
